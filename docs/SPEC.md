# 数据规范 · 史纲毛中特时间线大观

## 0. 一句话
以史纲为时间主轴、毛中特理论挂靠其上的「考研政治考点大观」：时间线 / 地图 / 脉络 / 辨析 四视图 + 详情面板 + 全字段速查。

## 1. 数据分层
| 文件 | 作用 | 谁写 |
|---|---|---|
| `data/master.json` | 骨架：每个节点的 id / 年份 / 标题 / 时期 / 轨道 / 类型 / 教材出处 / 考频 / 地点 / 线索 | Lead（已定，勿改结构） |
| `data/parts/e*.json` | 文案：每个节点的 `sec` 五段内容 | 内容 agent |
| `data/threads.json` | 8 条跨期线索的导读 | 内容 agent |
| `data/contrasts.json` | 8 张易混辨析表 | 内容 agent |
| `data/theory.json` | 毛中特 7 大理论专题树 | 内容 agent |

## 2. 节点骨架字段（master.json，已固定）
```json
{"id":"1842_nanjing","y":1842,"mo":8,"d":29,"label":"《南京条约》签订",
 "era":1,"track":"s","cat":"条约","ch":"纲要·1章1节","star":5,
 "place":"南京","prov":"江苏","threads":["侵略与抗争"],"pair":""}
```
- `y` 年（数字）／`mo` 月 1-12（可省）／`d` 日（可省）
- `era` 1-6：1 旧民主主义革命(1840-1919)、2 新民主主义革命(1919-1949)、3 社会主义革命(1949-1956)、4 社会主义建设探索(1956-1978)、5 改革开放新时期(1978-2012)、6 新时代(2012-)
- `track`：`s` 史实线 / `m` 理论线（毛中特·概论）/ `x` 新时代（习思想）
- `cat`：战争／条约／运动／起义／会议／著作／事件／制度／外交／人物／建设
- `ch`：教材出处，格式固定 `纲要·1章1节` / `概论·2章2节` / `习思想·5章`
- `star`：1-5，考频经验估计
- `prov`：省级行政区名（地图高亮用），`place` 为具体地名；无地理位置意义则两者均为 `""`
- `pair`：跨轨对应节点 id（史实 ↔ 理论），无则 `""`

## 3. 文案字段（parts，本次任务核心）
每个节点输出一个对象，**只写下面这些字段**（骨架字段不要重复写）：
```json
{"id":"1842_nanjing",
 "sec":{
   "bg":"背景（60-110字）",
   "main":"主要内容（90-170字，可用①②③分点）",
   "sig":"历史意义/影响（60-110字）",
   "tip":"考点提示：怎么考、常错点（40-80字）",
   "mix":"易混辨析：与相邻概念的区分（30-80字，无则空串）"
 },
 "kw":["搜索关键词","同义表述","口诀"],
 "dgt":"对应大纲考点名称（可选，如：鸦片战争是中国近代史的起点）"}
```

### 硬性要求
1. **一切表述以三本 2023 版教材为准**（语料见 §6）。关键论断优先用教材原话（可摘句，加引号），不得改写原意。
2. **禁止编造**：不写教材没有的细节、数据、引文；不确定的会议届次/文献名/年份一律不写，宁可省略。
3. 术语首次出现用全称；同一节点内不要重复标题。
4. `tip` 写"考什么"（选择题常考对应关系/时间排序/概念区分；分析题常考意义），`mix` 写最容易混的那一组。
5. `kw` 3-6 个，覆盖：人物、会议名、文献名、口诀（如"三大法宝""两个务必"）、易搜别名。
6. 中文标点；不用 markdown 语法（不要 `**`）；不用 emoji。

### 字数与口吻
- 面向备考学生，短句、断言式，不铺陈。
- `main` 若为多要点，用 ①②③ 编号，每条一句。
- 意义类表述区分：`sig` 写历史地位/转折点/影响；`tip` 写命题角度。

## 4. 输出文件格式（重要）
每个 agent 只写自己那一个文件，UTF-8 无 BOM，内容是**严格 JSON 数组**（不是 JS）：
`data/parts/e1.json`
```json
[
  {"id":"1839_humen","sec":{...},"kw":[...],"dgt":"..."},
  {"id":"1840_opium","sec":{...},"kw":[...],"dgt":"..."}
]
```
- 数组元素顺序与分配给你的 id 顺序一致。
- 只包含分配给你的 id，**不多不少**。
- 写完后自己用 `python -c "import json;json.load(open(...,encoding='utf-8'))"` 验证一遍能解析。

## 5. threads / contrasts / theory 格式
`data/threads.json`：8 条线索，每条
```json
{"id":"th_invade","name":"侵略与抗争","color":"#a33",
 "summary":"60-100字：这条线索讲什么、为什么重要",
 "stages":[{"t":"1840-1901","text":"该阶段这条线索的关键变化（40-70字）"}, ...],
 "nodes":["节点 id 若干，从 master.json 里按主题挑"]}
```
`data/contrasts.json`：8 张表
```json
{"id":"c_oldnew","title":"旧民主主义革命 vs 新民主主义革命",
 "why":"为什么容易混（30-60字）",
 "cols":["比较项","旧民主主义革命","新民主主义革命"],
 "rows":[["领导阶级","资产阶级","无产阶级（中国共产党）"], ...],
 "conclusion":"一句话记忆锚点"}
```
`data/theory.json`：7 大理论专题树
```json
{"id":"t_mao","name":"毛泽东思想","period":"1921-1976","book":"概论 1-4章",
 "core":"回答的核心问题（30字内）",
 "parts":[{"name":"新民主主义革命理论","points":["...","..."]}, ...],
 "status":"历史地位（60字内）",
 "nodes":["对应史实节点 id"]}
```

## 7. 铁律（违反即返工）
- 日期/文献名/会议名/人物与教材一致；教材未载的存疑内容一律不写。
- 不写小说式描写、不写主观感慨、不写"据说"。
- 每个 id 都要有内容，不能留空。
