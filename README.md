# 中国近现代史 · 时间线大观

考研政治「中国近现代史纲要 + 毛泽东思想和中国特色社会主义理论体系概论」复习工具。
165 个考点（139 个原始考点 + 13 个会议补全 + 13 个大纲补全节点）、6 个时期、9 条专题线索、7 个理论专题、18 张易混辨析表、39 张大纲补遗卡、一份考纲对齐清单，全部收在一个本地网页里。
每个考点都标了**双轨出处**：教材章节（`史纲 5章2节`）+ 2027 考试大纲条目（`大纲 史纲 6章3节`）。

**打开方式**：双击 `index.html`（无需联网、无需安装、无需启动服务器）。

**在线版（发给朋友用这个）**：<https://6huang6.github.io/kaoyan-zhengzhi-timeline/> —— 手机/平板/电脑浏览器直接打开，无需下载。

## 一、五个视图，各管一件事

| 视图 | 解决的问题 | 怎么用 |
|---|---|---|
| **时间线** | 「这件事在什么位置、前后是什么」 | 横向拖动平移、滚轮缩放；点节点或点标签看知识点；上方时期条一键跳到某段（**只导航不过滤**，其余时期的点仍在，再点一次回到全部）；六个时期之间的虚线分界**就落在分界事件上**（菱形标记 + 顶部小字：1919 五四运动 / 1949 新中国成立 / 1956 三大改造完成 / 1978 真理标准讨论 / 2012 中共十八大） |
| **地图** | 「这事发生在哪、哪几个考点挤在一个地方」 | 省份深浅=考点密度；点红点看该地全部考点；滚轮缩放、拖动平移 |
| **脉络** | 「毛中特不是时间轴，怎么按理论块记」 | 三个页签：**专题线索**（9 条跨期主题，如「统一战线」从 1923 到 2024、「关键会议」把 46 个会议按定路线/定制度/定理论串成一条）、**理论专题**（7 棵专题树，从「回答什么问题」到要点）、**大纲补遗**（39 张补遗卡，大纲要求但挂不上时间点的知识点，按史纲/毛中特/习思想分组） |
| **辨析** | 「长得像的概念怎么区分」 | 18 张对照表，按 全部 / 史纲 / 理论 / 综合 筛选：新旧民主主义革命、洋务/维新/辛亥、三大法宝、两次国共合作、土地政策五步、计划与市场四次表述…每张表底部可点回对应考点 |
| **考纲** | 「大纲要求什么、我漏了什么」 | 163/165 条已标大纲归属；「缺口 53」列出**大纲要求但本库曾没有专条**的考点（附教材原文行号与补法建议），其中 52 条已补（标「已补·去看」可直接跳转），剩 1 条未展开；「超纲 4」列出本库有而大纲无对应的条目 |

右侧详情面板对五个视图通用，内容依次为：
`背景 → 主要内容（①②③）→ 历史意义 → 考点提示 → 易混辨析 → 大纲考点 → 关键词`
顶部三档标注：**时期**（旧民主主义革命/新民主主义革命…）、**轨道**（史实线/理论线/新时代）、**类型**（会议/事件/著作/战争…）、**考频 ★1–5**；meta 行同时给出**教材章节**与**大纲条目**两处出处。

## 二、三个「查」的入口

1. **搜索**：`Ctrl + K` 或点右上搜索框。搜考点标题、关键词、会议名、口诀（如「三大法宝」「两个务必」）、年份、地点都能命中，命中处高亮。
2. **速查模式**：详情面板右上「速查」按钮 → 隐藏「背景」段，只留要点与易混，一屏扫完。
3. **只看高频 ★4+ / 只看未掌握**：时间线工具栏的筛选，把复习范围收窄。

## 三、快捷键

| 键 | 作用 |
|---|---|
| `←` `→` | 上一个 / 下一个考点（按时间顺序） |
| `Ctrl + K` 或 `/` | 打开搜索 |
| `↑` `↓` `Enter` | 搜索面板内选择 / 打开 |
| `Esc` | 关闭搜索或详情面板 |
| `Home` | 回到首页 |

鼠标：拖动平移、滚轮以光标为锚缩放、右下角小地图可直接拖定位。
圆点不好点时有个容错：在轴附近（上下 24px 内）点空白处，会吸附到离你最近的那个考点。
标签在空间不够时会自动分层排布，实在排不下的少数标签会先隐藏，放大或悬停（看 `title`）即可确认；「总览」按钮把 165 个考点一次铺满，此时只剩圆点、没有名称，滚轮放大就回来。
详情面板底部三档 **未学 / 学习中 / 已掌握**，进度存在浏览器本地（localStorage），关掉再开还在；顶栏进度条统计已掌握数量。

## 四、建议的三种用法

- **第一轮铺面**：时间线拉到 36% 左右，从 1840 一路拖到 2024，只看标题和 ★，建立「谁先谁后」的骨架。
- **第二轮啃理论**：进「脉络 → 理论专题」，按 7 个专题各看一遍，每个专题把底部考点胶囊点开，确认「这个理论回答了什么问题、包含哪几条」。
- **考前查漏**：`Ctrl+K` 搜易混概念 → 进「辨析」对照 → 用「只看未掌握」扫一遍剩下的。

## 五、关于准确性（请读这一段）

- 全部文案以**高等教育出版社 2023 年版马克思主义理论研究和建设工程重点教材**为准：
  《中国近现代史纲要》《毛泽东思想和中国特色社会主义理论体系概论》《习近平新时代中国特色社会主义思想概论》。
- 每个考点都标了出处章节（如 `史纲 5章2节`、`概论 2章2节`），文案写作时逐条比对教材原文；三本教材全文留在 `src/ref/*.txt` 备查。
- 文案完成后做过一轮**交叉核查**（写完的人互相查，不查自己的部分），逐条 grep 教材原文比对年月日、会议届次、文件与人名配对、引文与数字，报告留在 `docs/VERIFY-*.md`；共确证 15 处与教材冲突并已改正（例如 1972 年上海公报不能写「美方承认」、1971 年是「恢复」联合国合法席位而非「成为」常任理事国），另有若干措辞按教材口径收紧。
- **考频 ★ 是「近十几年真题考查频度的经验估计」，不是官方数据**，只用来排复习优先级，不要当成命题预测。
- 教材表述有细微差异的地方（例如某些会议的具体月日、某提法的首次出处），以教材正文为准；个别 2023 版教材未覆盖的近年新提法已按公开事实补齐，并在出处栏标注锚定章节。
- 发现任何与教材不符之处，改 `data/parts/e*.json` 对应字段后运行 `node tools/build.js` 即可更新页面（见下）。

### 关于「官方大纲」（现在已经有原文了）

考研政治**没有官方推荐书目**。官方只出两种东西：教育部教育考试院编的《思想政治理论考试大纲》（高教社，2027 版 ¥18，ISBN 978-7-04-068500-8）和配套的《大纲解析》。前者是纸质书，官方不提供免费电子版——网上流传的几种「完整版」我逐一下载核过，都是旧版或某校课程大纲，不能用（踩坑记录见 [`docs/OUTLINE.md`](docs/OUTLINE.md)）。

你后来把 **2027 大纲 PDF** 提供了，所以现在出处是**双轨**的：

- `ch` = 教材章节（`史纲 5章2节`），保证每句话能在三本 2023 版马工程教材里找到原文；
- `ol` = 大纲条目（`大纲 史纲 6章3节`），163/165 条已对齐（未对齐的两条是 2024 年二十届三中全会与 2025 年二十届四中全会，2023 版教材未收录，后者属时政）。

两者并非一一对应，这是正常的：大纲把「导论」也算一章，所以**毛中特、习思想的教材章号比大纲小 1**；史纲第六章大纲多出「抗日民族统一战线的建立与全民族抗战开始」这一节，1935—1937 那 4 条因此是「教材 6章2节 → 大纲 6章3节」。逐条差异写在 [`docs/GAPS.md`](docs/GAPS.md) 与 `docs/align-*.md`。

**「考纲」视图**把两件事摆出来了：53 条「大纲有、本库曾缺」（每条都给教材原文行号与补法建议），4 条「本库有、大纲无对应」（多为教材背景或时政）。其中 **52 条已补**：13 条有明确历史坐标的补成了时间线节点（三反五反、《党和国家领导制度的改革》、强军目标、总体国家安全观、香港国安法、「十四五」规划纲要、南京国民政府成立、东北抗联、国民参政会、三三制、豫湘桂战役、第二条战线、五一口号），另外 39 条理论型知识点做成「脉络 → 大纲补遗」卡片，并在挂靠考点的详情面板底部显示。剩 1 条（史纲 9 章 2 节「经受严重政治风波的考验」）涉及敏感历史叙述，本工具不展开，读者按教材原文自行掌握。

时政（约 13%）本项目故意不做——每年换，且没有教材可溯源，硬写会破坏「每条可溯源」的底线。

## 七、改数据后怎么重新生成

```bash
node tools/build.js
```

脚本会校验（五段字数、字段完整性、id 唯一、关键词数量），通过后重新生成 `data/master.js`、`data/parts/*.js` 等构建产物，页面刷新即可看到。校验不通过会打印 `✗` 清单，按提示改 JSON 再跑一次。

## 八、分享给朋友 / 部署到 GitHub Pages

这个页面是纯静态的（无后端、无数据库），三种给别人的方式：

1. **发文件夹**：把整个目录（或 `dist/` 目录）压缩发过去，对方解压后双击 `index.html` 即可，无需联网。
2. **本机开服务**（同一 Wi-Fi 下手机/平板也能访问）：
   ```bash
   python -m http.server 8123 --bind 0.0.0.0
   ```
   然后用 `http://<你的电脑内网 IP>:8123/` 打开。
3. **GitHub Pages（推荐，永久地址，谁都能开）**：
   - 线上地址：<https://6huang6.github.io/kaoyan-zhengzhi-timeline/>
   - 重新发布（改了内容之后）：
     ```bash
     powershell -ExecutionPolicy Bypass -File tools/make_dist.ps1
     cd dist
     git add -A && git commit -m "update" && git push
     ```
     推送后 1 分钟左右自动更新（Pages 构建）。

### 发布集里有什么、没有什么

`dist/` 只放运行必需的文件（≈1.4MB、60 余个文件）：`index.html`、`css/`、`js/`、`data/`、`vendor/`、`docs/`、`tools/`、`README.md`。

**不含**：`src/ref/`（三本教材的 docx/txt 原文，属版权内容，只在本机做核对用）、大纲 PDF、`shots/` 截图。所以别人拿到的是成品页面 + 数据，不会拿到教材原文。

### 平板 / 触屏

- 顶上导航在窄屏变两行；时间线、地图支持**单指拖动 + 双指缩放**（`touch-action:none`，不会带动页面滚动）。
- 宽屏（>1024）详情面板在右侧；平板（≤1024）改为**底部抽屉**，点空白或右上角 × 收起。
- 触屏下主要按钮点按区已放大（详情操作 40px；时间线缩放按钮 26–30px 偏小），时间线标签仍分层排布，放大或悬停可看全名。

### 手机 / 平板

- **平板（768–1180 宽）**：时间线仍是横向大图，详情面板变成**底部抽屉**（不再占右半边）；地图改为「图在上、地名列表在下」；首页 2 列。
- **手机（≤640 宽）**：
  - 顶栏收成一行：印章 + 五个视图（可横向滑动）+ 搜索图标；
  - 时间线**双指缩放**、单指拖动；标签自动只保留 ★4 以上高频考点，放大后全部出现；
  - 详情面板上滑成 88vh 大抽屉，正文单栏；
  - 地图不画地名标签（点圆点 → 下方列表 / 详情），脉络·辨析·考纲全部单列；
  - 辨析表格横向可滑（表格有最小宽度，避免压成一行两字）。
- 触屏手势：拖动平移、双指缩放、单击看考点；首次进入会弹一次操作提示。
- 手机竖屏建议直接横过来看时间线，可视范围更宽。

## 九、离线单文件版（售卖 / 发送用）

把整个站点压成一个 `.html`，所有资源内联，双击即用、断网可用：

```bash
python tools/build_single.py
```

产物：`release/史纲时间线大观.html`（**约 850 KB**，单文件，与旧版同名、直接覆盖；同目录另有一份 `使用说明.txt`）。生成时会检查是否还残留本地引用，正常输出 `wrote release/...` 且没有 `WARN`。

- **内联了什么**：`css/app.css`、`vendor/china-geo.js`（地图）、`data/*.js`（考点数据）、`js/*.js`（10 个模块）、站点图标（转成 data URI）。因为全部内联，`file://` 下不会被浏览器拦外部资源。
- **没内联**：`manifest.webmanifest`（离线打开没有「安装到主屏幕」场景，已移除）、教材原文、大纲 PDF、截图。
- **功能等价**：与线上版是同一份代码与数据，五个视图、搜索、速查、掌握度、考纲缺口全部可用；掌握度存该设备浏览器 localStorage。
- **已验证的视口**：390×844（手机）、768×1024（平板竖屏）、1440×900（桌面），五个视图逐页截图确认无横向溢出、无 JS 报错（`nodes=165`）。
- **iPad 提醒**：iPadOS 没有「用浏览器打开本地文件」的入口，直接点文件只会走系统「快速预览」（可能白屏或只剩文字）。iPad 买家要么用免费 App（Documents 之类）打开，要么直接给线上链接。电脑与 Android 双击/选 Chrome 打开均正常。
